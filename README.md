# PCL2 2.14.0.0 可下载版（官方原版归档）

>  **非官方仓库。** PCL（Plain Craft Launcher 2）由 **龙腾猫跃** 开发，本仓库仅归档一个官方发布过的旧版本，未做任何修改。

## 这是什么

PCL2 **2.14.0.0**，官方 2026-10-19 发布的构建。

2026-10-20 作者发布 `2.99.0.0`，更新日志全文只有一句：

> 为遵守相关法律法规，PCL 不再提供 MC 下载功能，非常抱歉 qwq……

也就是说，2.99.0.0 起启动器不再能下载 Minecraft。本仓库归档的是**移除该功能前的最后一个版本**，给仍需要这个功能的人自取。

## 下载

到 [Releases](https://github.com/Zzz528/pcl-2.14.0.0-archive/releases/latest) 下载 `PCL2-2.14.0.0.zip`。

短地址（自动跳转到下载页）：<https://zzz528.github.io/pcl-2.14.0.0-archive/>

解压即用，免安装，删文件夹就等于卸载。

## 用法

1. 解压到 D 盘，例如 `D:\PCL\`
   不要放桌面、C 盘、Program Files —— 要么没写权限，要么路径带空格
2. 双击 `Plain Craft Launcher 2.exe`
3. 弹出「Windows 已保护你的电脑」时：点「更多信息」→「仍要运行」

同意用户协议后，点「下载」→「原版」即可选择版本安装。

## 已知限制

- **绝对不要点「检查更新」**
  升到 2.99.0.0 后下载功能会消失，且是把代码模块删掉，不是开关，改配置文件救不回来。
- **CurseForge**
  CurseForge 自 2026-07-16 起封禁 `2.13.0.0` 以前的客户端。本版本 2.14.0.0 不在封禁范围；若 CF 页签异常，可在设置里把模组下载源切成 Modrinth。
- **新版本游戏**
  2026 年的 26.x 版本兼容性请自行测试。稳妥做法是 PCL 只负责下载，启动交给官方启动器。
